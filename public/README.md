# Carpeta `public/`

Los archivos estáticos (videos, imágenes, audio) que uses en tus composiciones van acá.

Para probar la composición de ejemplo `VideoExample` (ver `src/VideoExample.tsx`):

1. Copiá tu video acá con el nombre `sample-video.mp4`.
2. Corré `npm run dev` y abrí el Remotion Studio.
3. Seleccioná la composición **VideoExample** en el panel izquierdo.

El título mostrado sobre el video se puede cambiar desde el panel de "Props" del Studio (prop `title`).
